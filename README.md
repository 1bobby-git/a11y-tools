# 접근성 스튜디오 · a11y-tools

한국어 웹 접근성 점검 도구입니다. GitHub Pages에서 보고서를 검토하고, Chrome/Edge 확장 프로그램으로 현재 페이지를 검사합니다. 자동 결과는 법적 적합성이나 인증 판정이 아닙니다.

온라인: https://1bobby-git.github.io/a11y-tools/

## v0.2.0: 문제를 찾고 수정할 수 있는 증거

중복 ID는 같은 DOM 트리별로 그룹화하여 첫 번째 요소를 포함한 모든 대상을 보여줍니다. 각 요소의 독립 선택자, 현재 마크업, 새 ID 예시와 연결된 `for`·ARIA·앵커를 함께 확인합니다. 다른 Shadow DOM의 같은 ID는 합치지 않습니다. 닫힌 Shadow DOM과 프레임 내부는 별도 검사 대상입니다.

axe HTML을 통째로 버리던 처리를 제거했습니다. 자식 마크업과 ID·class·role·alt·ARIA·레이블 관계를 보존하며 입력값, 실행 코드, 민감한 data 속성, URL 인증정보와 쿼리를 제외합니다. 화면 텍스트에는 개인정보가 남을 수 있습니다. 보고서 공유 전 확인하세요.

오류마다 문제의 영향, 현재 코드, 참고 수정 예시, 수정 후 확인 절차를 표시합니다. 예시는 실제 기능·이미지 의미에 맞춰 적용해야 하며 원본 사이트를 자동 수정하지 않습니다. 아직 전용 예시가 없는 규칙은 실패 조건과 기존 수정 안내를 표시합니다.

격리 재구성 미리보기는 원본 스크린샷이 아닙니다. 스크립트·외부 리소스·네트워크를 차단합니다. 확장 보고서의 **원본 영역 캡처**는 확인 후 실제 보이는 부분만 저장하고 입력 필드를 가립니다. 화면 텍스트는 별도 검토가 필요합니다. 원본 DOM이 달라졌으면 다시 검사해야 합니다.

## 시작하기

Node.js 20 이상에서 저장소 루트에서 실행합니다.

```sh
npm install --ignore-scripts
npm run build
npm start
```

Windows에서는 `START-LOCAL.cmd`를 사용할 수 있습니다. 로컬 서버 주소는 실행 로그를 확인하세요. 배포 빌드는 axe-core 설치를 필수로 요구합니다.

Chrome/Edge 확장 관리에서 개발자 모드를 켜고 빌드된 `extension/`을 압축해제 확장으로 로드하세요. 온라인 도구의 **확장 프로그램 ZIP**도 같은 빌드로 생성됩니다. 업데이트한 파일을 적용한 후 확장 관리 화면에서 **새로고침**, 대상 사이트도 새로고침한 뒤 재검사하세요. 기존 보고서에 없는 마크업은 업데이트만으로 복원되지 않습니다.

## 검사 순서

1. 대상 페이지에서 메뉴·팝업 등 검사할 상태를 엽니다.
2. 확장에서 페이지를 검사하거나 실제 Tab·Shift+Tab 초점 기록을 시작합니다.
3. 보고서의 오류를 열어 전체 대상, 연결 속성, 마크업·미리보기·수정 예시를 확인합니다.
4. 수정 후 같은 뷰포트·화면 상태에서 재검사합니다. 이미지 의미·자막 정확성·논리 순서는 수동 검토에 기록합니다.

HTML 입력은 원본 스크립트와 외부 리소스를 차단한 격리 화면 검사입니다. 실사이트의 완전한 레이아웃·동작 검사와 다릅니다. JSON·HTML 내보내기에는 대상별 마크업과 연결 참조가 포함됩니다.

## 실제 스크린리더

[실행 안내](SCREEN-READER.md)의 로컬 실행부는 Guidepup으로 Windows NVDA 또는 macOS VoiceOver를 제어하고 실제 발화를 저장합니다. DOM 이름을 합성 음성으로 읽고 실제 검사로 표시하지 않습니다. 명령별 발화, 선택적 기대 문자열 검사, 같은 시점의 DOM 초점과 레이아웃 차이를 기록합니다.

브라우저 접근성 트리, Tab 순서, 스크린리더 가상 커서는 서로 같은 정보가 아닙니다. Pages·일반 확장만으로 운영체제 보조기술을 실행하지 않습니다. 실제 엔진을 실행하지 않은 보고서는 **미실행**으로 표시합니다. 로컬 실행부의 Windows/macOS 전체 흐름은 이번 Linux 환경에서 검증하지 못했습니다.

## 개발·배포

```sh
npm run build
npm test
python tests/browser_test.py
python tests/evidence_browser_test.py
```

브라우저 테스트에는 Python Playwright와 Chromium이 필요합니다. 실제 실행 결과와 미검증 범위는 [VERIFICATION.md](VERIFICATION.md)를 확인하세요. 기존 Pages 워크플로는 main 변경 시 의존성 설치, 빌드, 정적 테스트, 배포를 수행합니다. `docs/`, `extension/assets/`, 확장 ZIP은 `scripts/build.mjs`가 생성합니다.

핵심 규칙과 초점 기록기는 유지하고 `public/assets/evidence.js`, `evidence-ui.js`로 증거 수집·표시를 확장했습니다. `runner/`는 선택적 데스크톱 보조기술 실행부입니다.

## 한계·보호

보고서 최대 2,500개 발견, 노드별 마크업 64,000자 제한이며 잘림을 표시합니다. 미검사를 통과로 처리하지 않습니다. 자동 외부 전송·분석 추적 없음. 확장 보고서는 브라우저 로컬 저장소에 유지되므로 공유 PC에서는 삭제하세요. 입력값 마스킹이 완전한 익명화를 뜻하지 않습니다.
