초점 이동의 흔적

사용자가 실제로 이동한 순서와 화면의 변화를 함께 확인합니다.

키보드 초점 ≠ 스크린리더 읽기 커서

Tab 타임라인은 DOM 초점 기록입니다. 실제 발화는 별도 NVDA·VoiceOver 실행 보고서를 가져와 아래에서 확인하세요. 논리적 순서의 적절성은 직접 검토해야 합니다.

기록 방법

대상 탭에서 확장 프로그램의 초점 기록 시작 → 페이지로 돌아가 Tab / Shift+Tab 이동 → 중지하고 보고서 순서로 실행하세요.

버튼 클릭·자동 Tab 이동·화면 스타일 변경을 하지 않습니다. 120ms와 500ms 후의 크기·좌표·가림 상태와 입력 직후 레이아웃 변화를 기록합니다.

DOM 기준 초점 후보 순서 (실제 Tab 기록 아님)

양수 tabindex, 라디오 그룹, 복합 위젯, iframe, 동적 상태 때문에 실제 이동 순서와 다를 수 있습니다.

자동 결과를 수동 통과로 전환하지 않습니다. 통과·실패·해당 없음은 검토자가 직접 선택하며, 기록은 JSON/HTML 내보내기에 포함됩니다. 다른 보고서를 열기 전에 저장하세요.

서버 저장은 하지 않습니다. 현재 보고서의 브라우저 세션에서만 유지됩니다.

GET STARTED

사용 안내와 검사 범위

1. Chrome / Edge 확장 프로그램 설치

  1. 확장 프로그램 ZIP을 받고 압축을 풉니다.
  2. Chrome의 chrome://extensions 또는 Edge의 edge://extensions를 엽니다.
  3. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다에서 manifest.json이 있는 폴더를 선택합니다.
  4. 검사 대상 페이지에서 확장 아이콘을 누른 후 이 페이지 검사를 실행합니다.
  5. 확장 프로그램의 보고서는 로컬 탭에서 열립니다. JSON을 저장한 뒤 이 웹에 가져올 수도 있습니다.

웹 스토어 배포본이 아닙니다. activeTab·scripting·storage만 요청합니다. 모든 사이트를 상시 읽거나 로그인 쿠키를 수집하지 않습니다.

2. 초점과 화면 변화를 확인하기

초점 기록을 시작한 후 페이지의 Tab·Shift+Tab·위젯 방향키를 직접 사용하세요. 메뉴를 열거나 모달을 닫는 실제 동작도 함께 테스트합니다. 페이지가 완전히 새로 로드되면 재시작해야 하며, 새 문서는 별도 검사 범위입니다.

가로 넘침 증가, 주변 구역의 좌표·크기 변화, 화면 밖 초점, 가림 표본을 기록합니다. 의도된 메뉴 확장·애니메이션도 잡힐 수 있으므로 레이아웃 변화는 자동 실패가 아니라 검토 단서입니다.

3. 이 도구가 하지 않는 것

URL만으로 외부 서버를 크롤링하거나 전체 사이트를 인증하지 않습니다. 원본 HTML 문법의 완전한 유효성 검사, 가상 커서의 정확한 화면 좌표 추적, 영상 자막의 의미 분석, 닫힌 Shadow DOM과 iframe 내부 검사는 포함하지 않습니다. 실제 NVDA·VoiceOver 발화 수집은 저장소의 SCREEN-READER.md에 있는 별도 데스크톱 실행기를 사용합니다.

기본 DOM 규칙은 일부 명확한 누락과 검토 후보를 찾습니다. 배포 시 axe-core가 번들되면 추가 규칙을 실행합니다. 엔진이 없거나 실패하면 axe 미실행으로 표시하며 미검사를 통과로 취급하지 않습니다.

결과는 법률 자문 또는 법적 적합 판정이 아닙니다. 장차법·품질인증 관련 최종 판단에는 적용 범위와 전문 검토가 필요합니다.

개인정보와 보관

이 앱은 분석 데이터 전송, 분석용 외부 API, 추적기를 사용하지 않습니다. 쿠키 저장소를 읽지 않으며 마크업의 입력값·비공개 속성·URL 인증정보와 쿼리를 가립니다. 원본 화면 캡처는 확인 후에만 저장합니다. 화면 텍스트·대체텍스트·레이블·선택자·발화에는 개인정보가 포함될 수 있으므로 공유 전에 검토하세요.

확장 프로그램의 최근 보고서 1건은 브라우저 로컬에 저장됩니다. 확장 프로그램에서 삭제할 수 있습니다. 웹 보고서는 sessionStorage에 저장되며 이 페이지의 로 제거할 수 있습니다.
